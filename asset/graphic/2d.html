2D 그래픽 에셋

2D 그래픽 에셋은 비교적 작은 용처에서 오늘의집 주요 서비스의 성격과 특징을 대표합니다. 사용자가 서비스를 직관적으로 선택하고 사용할 수 있도록 안내하는 역할을 합니다.

조형원칙

2D 그래픽 에셋은 아래 원칙에 따라 통일된 인상을 갖도록 제작됩니다.

심볼을 닮은 형상

아이콘과 마찬가지로, 2D 그래픽 에셋 또한 심볼의 하단 곡선에서 차용한 Smoothing Line을 조형에 일부 반영하여 제작합니다. 다만 반드시 적용해야 하는 요소는 아니며, 조형의 주요 곡선 요소 외에는 5px의 작은 Radius로 모서리를 처리하여 에셋이 전반적으로 선명한 인상을 갖도록 합니다.

간결한 구조

2D 그래픽 에셋은 작은 화면에서도 사용자의 서비스 인지성을 높일 수 있도록 최대한 간결하게 제작됩니다. 하나의 에셋은 서비스를 가장 객관적으로 설명할 수 있는 하나의 오브젝트로 구성되어야 하며, 두 개 이상의 오브젝트를 사용해 복잡한 인상을 주어서는 안 됩니다.

제작 그리드

2D 그래픽 에셋은 480×480 크기의 그리드 위에서 제작됩니다. 그리드는 터치 편의성을 위해 40px의 패딩 영역을 포함하며, 에셋은 이 패딩 영역을 최대한 침범하지 않는 균일한 크기로 제작됩니다.

컬러 사용

2D 그래픽 에셋은 정해진 브랜드 컬러 팔레트를 사용하여 제작됩니다. 그 외의 색상은 빅프로모션용 숏컷 제작을 제외하고는 가급적 사용을 금합니다. 시인성을 높이기 위해 에셋은 최대한 하나의 컬러로 제작되어야 하며, 표현에 한계가 있는 경우 두 가지 컬러까지 사용할 수 있습니다.

선의 사용

2D 그래픽 에셋은 기본적으로 면(Solid) 타입으로 제작됩니다. 조형 요소로서 선의 사용이 필요한 경우 선의 두께는 40px(Regular)에서 70px(Bold)까지 사용합니다. 선의 끝은 Square 타입으로 처리하되, 끝부분만 5px의 모서리 처리를 합니다.

폰트의 사용

2D 그래픽 에셋에서 폰트 사용이 필요한 경우 시스템 폰트인 Pretendard를 사용합니다. 에셋에서 폰트 사용은 가급적 최소화합니다.

사용 사례

에셋의 사용

2D 그래픽 에셋은 홈 숏컷처럼 서비스를 나타내는 역할로 적용되어야 합니다. 즉각적인 기능으로 이어지는 아이콘 영역이나 프로모션의 키비주얼과 같이 용처가 큰 영역에서 활용해서는 안 됩니다.

색상과 각도

지정된 브랜드 컬러 팔레트 외에 임의의 색상을 사용하여 에셋을 제작하지 않습니다. 또한 에셋의 각도를 임의로 회전시켜 적용해서는 안 됩니다.
